# Rock prefabs

Drag these prefabs into either night scene. Models use metres, unit scale, bottom-centred pivots, rough Standard stone materials and convex MeshColliders. No scripts, networking components or scene changes are required. Each is a unique closed low-poly mesh with flat face normals and planar UVs.

| RockMedium | 1.75 x 1.15 x 1.35 | 64 |

| RockLarge | 4.60 x 2.65 x 3.50 | 90 |

Native meshes and portable OBJ copies: Assets/Art/Models/Rocks. Shared materials: Assets/Materials/Rocks. Preview: Logs/RocksPreview.png.

Built and visually checked in Unity 6000.0.32f1. Prefab mesh/collider references, closed edges, outward winding and positive volume verified. Generation source and validation evidence: Logs/RockAssetBuild.
