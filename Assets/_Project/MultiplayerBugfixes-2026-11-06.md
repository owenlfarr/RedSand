# Multiplayer playtest fixes ? 2026-11-06

- Movement Detected: run controller base layer weight is 1. MonsterRunImportFix enables loopTime on the actual Zombie Running FBX take, repairs the existing import on the next editor script reload, and maintains it on future imports. Tools > Monsters > Fix Run Loop can also apply it manually.
- Rush/flicker audio: one dedicated flicker source refuses another clip while its current clip plays. Approaching/passing cues replace the current event cue instead of accumulating one-shots. Same-scene duplicate AmbianceSystem components are suppressed; disabling a component stops its audio and fade.
- Power: restoring power restarts its timer and skips the first eligible outage check. For a 30-second interval, the first random/forced outage check is 60 seconds after restoration. The skipped check does not increment the forced-outage counter. Applies offline and on the server; clients receive the new timer.
- Removed Rush narrative warning text through the common ShowWarning entry point. Existing audio/light cues and kills are preserved.
- Living local players below 50 metres beneath the lower of their level spawn/terrain origin teleport to a level NetworkStartPosition. Clears falling velocity and landing impact; owner NetworkTransform teleports peers too. Runs with the menu open. Does not revive dead players or reset oxygen, inventory or shared resources. Wall collision geometry itself was not changed.
- Public browser initially covers its list with CONNECTING / Loading public servers until authentication and the first query complete (including empty/error results). Closing invalidates old results and preserves cancellation. Normal background refresh retains the list.

Validation: gameplay sources and the new editor importer compiled successfully using Unity 6000.0.32f1 Roslyn and cached Unity/package references (Logs/MultiplayerBugfixCheck.dll). No fresh executable build or host/client audiovisual playtest has been run for these changes. The active Unity editor must refresh/reimport the model before a new build. Existing unrelated scene, material, font, power-light and solar-flare edits were preserved.
